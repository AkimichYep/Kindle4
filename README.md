# Kindle Drone Tools

This project is organized as a standard Maven Java layout.

## Project Structure

- `src/main/java` - Java sources (`KindleWifiHud`, `KindleDroneDetector`, `KindleSpectrum`, etc.)
- `src/main/resources` - runtime resources (currently empty)
- `src/test/java` - tests (currently empty)
- `target` - build output (generated by Maven)

Legacy compiled artifacts from the previous flat layout were moved to:

- `target/legacy-artifacts`

## Build

```bash
mvn -DskipTests package
```

## Run (examples)

```bash
java -cp target/classes KindleWifiHud
java -cp target/classes KindleDroneDetector
java -cp target/classes KindleSpectrum
java -cp target/classes KindleSpectrum active
```
